# Fisio e Sports

Gestionale per centri di fisioterapia e riabilitazione. Il progetto sta
evolvendo da una webapp Java verso un backend condiviso e client autonomi per
desktop e Android. Il database MySQL e la webapp esistente restano disponibili
durante la transizione.

Il sistema comprende anagrafica e anamnesi, calendario, trattamenti, lista
d'attesa, statistiche e promemoria WhatsApp. Il codice Java è organizzato in
moduli per dominio, logica applicativa, persistenza MySQL, webapp legacy e nuovo
backend.

La [guida alla documentazione](docs/README.md) raccoglie struttura del sistema,
istruzioni operative, migrazioni e stato dei lavori. Per la ricognizione delle
funzioni esistenti consulta l'[inventario funzionale](docs/architecture/02-inventario-funzionale.md).
